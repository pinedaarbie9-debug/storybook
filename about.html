About Storybook

A cozy corner for short stories

Storybook is a Wattpad-inspired reading platform built as a school project. It shows how a simple website can bring stories to life using only HTML, CSS, and JavaScript, with no database and no login.

Comfortable reading

Dark mode, adjustable text size, a focus mode, and a progress bar that remembers where you stopped.

Project description

This project was built with plain HTML, CSS, and JavaScript. The books live in organized data files, and shared JavaScript builds each page from them.

  • Semantic HTML: header, nav, main, section, article, and footer
  • CSS Grid, Flexbox, media queries, and smooth hover transitions
  • localStorage for theme, likes, saved books, and reading progress
  • Responsive layout with a collapsible mobile menu
